# Home OS — Topsee Command

A personal home-command dashboard: a vanilla-JS PWA (no framework, no build step) backed by a
small FastAPI service, scaffolded via Emergent and developed iteratively from there.

This repository used to also hold an unrelated project (a gamified welding course), under a name
that no longer fit either. That project has moved to its own repository:
[topseecrets11/welding-wizard](https://github.com/topseecrets11/welding-wizard). This repo now
holds Home OS alone.

## Architecture

- Vanilla JS IIFE app: `frontend/public/homeos.js`
- Flat CSS: `frontend/public/homeos.css`
- Shell: `frontend/public/index.html`
- PWA: `manifest.json` + `service-worker.js`
- Client storage: `localStorage` key `homeOS` (cached, O(1) reads)
- Backend: `backend/server.py` — FastAPI + Motor (MongoDB), CORS-enabled, stock status-check
  endpoints (`GET /api/`, `POST /api/status`, `GET /api/status`)
- `frontend/` is otherwise a standard CRA + craco + Tailwind + shadcn/ui scaffold generated by
  Emergent; the real application lives in `frontend/public/homeos.*` above.

See `memory/PRD.md` for the full feature history and phase-by-phase test results, and
`test_reports/` for the underlying iteration reports.

Open backlog items (P1): VIRGIL LLM integration, real Tuya/Sentry device APIs, data export
improvements. See `memory/PRD.md` for the complete backlog.

## Running locally

Backend:

```
cd backend
pip install -r requirements.txt
uvicorn server:app --reload
```

Frontend: the real app is static (`frontend/public/`), so it can be served directly, or through
the CRA dev server (`cd frontend && yarn install && yarn start`) for the scaffold's tooling.
